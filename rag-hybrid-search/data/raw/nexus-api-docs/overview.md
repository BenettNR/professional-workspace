# Nexus API — Overview

Nexus is a real-time data processing API designed for high-throughput event ingestion,
transformation pipelines, and analytics delivery. It is built on an async-first
architecture and provides SDKs for Python, Go, TypeScript, and Java.

## Core Concepts

### Streams
A **stream** is an ordered, append-only log of events. Each stream has a unique name
(e.g. `org.acme.payments`) and belongs to exactly one **workspace**. Streams are the
primary unit of data organisation in Nexus.

### Events
An **event** is a JSON object published to a stream. Every event is assigned:
- A monotonically increasing `sequence_number` (uint64)
- An `event_id` (UUID v4) generated by the server
- An `ingested_at` timestamp (RFC 3339, UTC)

### Pipelines
A **pipeline** is a directed acyclic graph (DAG) of **processors** that transform,
filter, or enrich events as they flow through Nexus. Pipelines consume from one or
more input streams and write results to output streams.

### Workspaces
A workspace is the top-level isolation boundary. Resources (streams, pipelines,
API keys) belong to a workspace and are not accessible from other workspaces unless
explicitly shared via workspace federation.

| Tier       | Description                                    | Max Streams | Max Events/Day |
|------------|------------------------------------------------|-------------|----------------|
| Developer  | Free, single-user                              | 5           | 100,000        |

| Enterprise | Unlimited, dedicated infrastructure            | Unlimited   | Unlimited      |

## API Versioning

Nexus uses URI-based API versioning. The current stable version is **v2**:

```
https://api.nexus.io/v2/
```

Version v1 is deprecated and will reach end-of-life on 2026-03-01. Clients should
migrate to v2 before that date. Breaking changes between versions are documented in
the [migration guide](migration.md).
